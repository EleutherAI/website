# basin-explorer

Interactive explorer for the dynamical model in
`content-blog/dynamical-models-of-ai-governability.md`. Built with Vite +
React; the deployed static build lives at `static/basin-explorer/` and is
served at `/basin-explorer/`.

```
npm install
npm run dev      # local dev server
npm run build    # builds straight to ../static/basin-explorer/ (commit the assets)
```

**The canonical math engine is `src/BasinExplorer.jsx`** — the **v5** model: a
two-stage detect-and-fix monitoring stock (documented `b` → fixed `s` at fix
rate `ρ`), a single `O_fix` suppression gate on all of `G_u = L_k + k_uu·q_u`,
growth-pegged passive opacity, and a turnover rate `γ` on the workforce share.
It holds the in-app ODE integrator, calibration (the `O*` dial pin), and the
analytic basin boundary. The blog post's equations and this app are kept in
sync; the post's live figures are generated by the v5 scripts in
`_scratch/review/verify-v5/` (e.g. `default_path_v5.py` for the default path,
`verify_v5.py` for the cross-checked landmark numbers).

`figures_ai2027.py` is a **SUPERSEDED v4** (`ℓ`/`ℓ_k` bounded-gate) port; its
outputs are no longer referenced by the post. Do not regenerate post figures
from it — port from `src/BasinExplorer.jsx` or reuse the v5 core in
`_scratch/review/verify-v5/`.

Note: a set of pre-δ helper scripts (`model.mjs`, `analytic.mjs`,
`scenarios.mjs`, `transients.mjs`, `explore_ai2027.mjs`) was removed in
June 2026 — they predated the destruction-fraction (δ) extension and asserted
results that are false for δ < 1 (e.g. a regime boundary independent of the fix
rate).
